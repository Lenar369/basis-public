# Контент-пакеты БАЗИС

Эта папка создаётся автоматически из публичных обновлений БАЗИС.

## Структура

- `dzen/` — готовые статьи для Дзена;
- `max/` — короткие посты для MAX;
- `manifest.json` — очередь материалов и статусы публикации.

Новые материалы получают статус `draft`. Это означает: текст уже подготовлен, но ещё не отправлен в канал.

## Правило ссылок

Для материалов про CRM БАЗИС используется ссылка:

**https://calcul369.ru**

Телефоны и `tel:` в эти материалы не добавляются.

## Защита от дублей

Будущие публикующие процессы должны брать материал из `manifest.json` только если для нужного канала стоит `status: draft`, а после успешной отправки менять статус на `published` и сохранять идентификатор/дату публикации.
