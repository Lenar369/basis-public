# БАЗИС для производственных компаний

БАЗИС развивается не только для строительных, но и для производственных компаний.

Производственной команде также нужны единые задачи, контроль исполнения, управленческая информация, расчёты и быстрый доступ к проблемным точкам.

## Направления применения

- контроль текущих задач;
- организация работы команды;
- отслеживание исполнения;
- управленческие показатели;
- уведомления и проблемные ситуации;
- внутренние расчёты;
- помощь сотрудникам внутри системы.

Функциональность для производственных сценариев будет расширяться по мере развития продукта.
