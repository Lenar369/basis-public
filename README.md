# БАЗИС

**CRM для строительных и производственных компаний**

БАЗИС помогает держать в одной системе объекты, задачи, экономику, расчёты, уведомления и работу команды.

🌐 Сайт: https://calcul369.ru

---

## Что решает БАЗИС

Когда информация разбросана по таблицам, чатам и заметкам, руководителю сложно быстро понять:

- что происходит на каждом объекте;
- где есть отклонения по срокам или деньгам;
- какие задачи требуют внимания;
- как выглядит план и факт по объекту;
- что нужно посчитать прямо сейчас.

БАЗИС собирает эту работу в одном месте.

## Основные возможности

### 🏗 Единая карточка объекта
Ключевая информация по объекту хранится в одном месте: состояние работ, задачи, экономика и связанные данные.

### 💰 План–факт и экономика объекта
Можно сопоставлять плановые и фактические показатели и быстрее видеть отклонения.

### 🔔 Центр уведомлений и проблем
Важные события и проблемные ситуации не теряются среди ежедневной работы.

### 🧮 Калькуляторы
Расчёты можно выполнять внутри системы, не переключаясь между отдельными таблицами и программами.

### 🤖 ИИ-помощник
Встроенный помощник помогает ориентироваться в системе, работать с расчётами и получать ответы по возможностям БАЗИС.

### 📘 Обучение и помощь
В системе развивается раздел помощи и интерактивное обучение, чтобы новым сотрудникам было проще начать работу.

## Для кого

БАЗИС развивается для компаний, которым важно управлять объектами, работами, людьми и экономикой в одной системе.

- строительные компании;
- монтажные организации;
- подрядчики;
- производственные компании;
- сервисные и проектные команды.

Система помогает вести объекты, контролировать выполнение работ, план–факт, экономику и проблемные точки.

## БАЗИС для производства

Подробнее: [БАЗИС для производственных компаний](docs/production.md)
