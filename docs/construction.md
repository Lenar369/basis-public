# БАЗИС для строительных компаний

Строительной компании важно одновременно контролировать объекты, людей, сроки, деньги и большое количество текущих задач.

БАЗИС объединяет эту информацию в одной системе.

## Что можно контролировать

- объекты;
- задачи и выполнение работ;
- плановые и фактические показатели;
- экономику объекта;
- важные уведомления;
- проблемные ситуации;
- расчёты;
- работу сотрудников.

## Зачем это руководителю

Вместо поиска информации по таблицам и чатам руководитель получает единое пространство для контроля текущей ситуации и отклонений.
