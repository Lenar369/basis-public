# Обзор БАЗИС

БАЗИС — CRM-система для управления повседневной работой строительных и производственных компаний.

## Идея продукта

Цель БАЗИС — уменьшить количество разрозненных таблиц, переписок и ручных действий. Руководитель и сотрудники получают одно рабочее пространство, где можно видеть объекты, задачи, расчёты, показатели и события.

## Основные принципы

- единая информация по объекту;
- понятный контроль план–факт;
- внимание к отклонениям и проблемам;
- встроенные расчёты;
- помощь пользователю внутри системы;
- развитие автоматизации и ИИ-функций.

## Безопасность публичной витрины

Этот репозиторий используется только для публичной информации о продукте. Исходный код БАЗИС, серверная конфигурация, секреты, ключи доступа и клиентские данные находятся вне публичного репозитория.
